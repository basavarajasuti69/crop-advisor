## How class mapping is generated and saved

1. `resolve_classes(train_classes, test_classes)` computes the sorted
   intersection of ImageFolder folder names, minus
   "Tomato two spotted spider mites leaf" (2 training images only).
   Result: 27 classes in alphabetical order.
2. `build_split(...)` carves 15% of each class from the train folder into
   validation (seeded per-class with `seed + train_label_index`).
3. `classes` (list of 27 strings) is saved to `classes.json` and
   embedded in `metrics.json`.
4. The model head is `Linear(1280, 27)`.

## How the validation split is created

- Carved from the **train** folder only (15% per class).
- Per-class shuffle seeded with `seed + train_label_index` (seed=42).
- Deterministic: same seed + same data = same split.
- Test folder is never used for training or model selection.

## Early stopping and cosine scheduler

- Cosine annealing: `CosineAnnealingLR(optimizer, T_max=epochs)`.
- Early stopping: stops after `patience` epochs without validation
  accuracy improvement, but never before `min_epochs`.
- Best checkpoint saved at best validation accuracy epoch.
- Test set evaluated only after training (for reporting, not selection).

## Proposed command

```bash
cd ~/crop-advisor
python ml/training/train_plantdoc.py \
    --data ml/training/experiments/plantdoc_deduplicated_v5/data \
    --epochs 40 \
    --batch-size 16 \

    --label-smoothing 0.1 \

    --validation-fraction 0.15 \
    --lr-scheduler cosine \
    --early-stopping-patience 8 \
    --early-stopping-min-epochs 10 \
    --out ml/training/experiments/plantdoc_27class_v11
```

Note: `--class-weighting` is omitted (disabled, matching V9).

## Expected training time

Based on V9: ~62 minutes (3,721.8 seconds for 32 epochs on MPS).
V11 has 2,318 training images (vs V9's 1,970), so expect ~70-80 minutes.

## Risks

1. **V5 has fewer training images** (2,318 vs V9's 1,970... wait, V5 has MORE: 2,318 vs 1,970). Actually V5 has 2,318 vs V3's 2,319. V9 used V3 (1,970 after split). V11 uses V5 (2,318 before split → ~1,969 after split). Similar.
2. **MPS non-determinism**: reruns may not reproduce exact metrics.
3. **Test set reuse**: test metrics are exploratory, not independent.
4. **Class imbalance**: some classes have very few examples (e.g., Corn Gray leaf spot: 62 train, 3 test).
